# Лаба 1 — Linux (задания 03, 04, 07, 08)

Один блок = одно задание. Копируешь целиком, вставляешь в терминал, жмёшь Enter.

Перед первым разом — одна строка настройки (в новом терминале повторять не нужно):

```bash
export DOTNET_ROOT="$HOME/.dotnet"; export PATH="$HOME/.dotnet:$PATH"
```

Все команды ниже работают из папки
`~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1`

## Задание 03 — статический вызов

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_lib
g++ -fPIC -shared SP.cpp -o SP.so
cd ../SP_03
cp ../SP_lib/SP.so .
g++ main.cpp SP.so -o SP_03
LD_LIBRARY_PATH=. ./SP_03
```

| Ключ | Значение |
|---|---|
| `-fPIC` | код грузится по любому адресу — обязательно для `.so` |
| `-shared` | делаем библиотеку |
| `SP.so` в `g++ main.cpp` | линкуем библиотеку (именно файл, не `-lSP` — тот искал бы `libSP.so`) |
| `LD_LIBRARY_PATH=.` | загрузчик ищет библиотеку в текущей папке |

**Ожидаем:** `sum = 15`, `sub = 5`, `mul = 50`, `div = 2`

**Показать преподавателю, что линковка статическая:**

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_03
readelf -d SP_03 | grep SP.so
```

`NEEDED  SP.so` — библиотека прописана в бинарнике, ОС грузит её сама.

## Задание 04 — динамический вызов (dlopen)

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_lib
g++ -fPIC -shared SP.cpp -o SP.so
cd ../SP_04
cp ../SP_lib/SP.so .
g++ main.cpp -ldl -o SP_04
./SP_04
```

| Ключ | Значение |
|---|---|
| `-ldl` | подключает `dlopen`/`dlsym` — в `libc` их нет |
| `SP.so` в команде **нет** | проект о библиотеке не знает, она грузится в runtime |
| `LD_LIBRARY_PATH` не нужен | путь задан прямо в `dlopen("./SP.so")` |

**Ожидаем:** `sum = 15`, `sub = 5`, `mul = 50`, `div = 2`

**Показать преподавателю, что линковки нет:**

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_04
readelf -d SP_04 | grep SP.so
```

**Пусто.** Вот это и есть главное доказательство — сравни с заданием 03.

## Задание 07 — C#, статический вызов (DllImport)

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/cs/SP_07
dotnet publish -c Release -r linux-arm64 --self-contained true -p:PublishSingleFile=true
cd bin/Release/net8.0/linux-arm64/publish
cp ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_lib/SP.so .
ls -lh SP_07 SP.so
./SP_07
```

| Ключ | Значение |
|---|---|
| `-c Release` | сборка без отладки |
| `-r linux-arm64` | под процессор ARM |
| `--self-contained` | .NET внутри файла, отдельно ставить не надо |
| `-p:PublishSingleFile=true` | всё в один файл |
| `cp SP.so .` | библиотека обязана лежать **рядом** с программой |

**Ожидаем:** `Сложение = 15`, `Вычитание = 5`, `Умножение = 50`, `Деление = 2`

**Размер файлов:** `SP.so` ≈ 69 КБ (наша C++-библиотека), `SP_07` ≈ 71 МБ (C#-обёртка).

## Задание 08 — C#, динамический вызов (dlopen)

```bash
cd ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/cs/SP_08
dotnet publish -c Release -r linux-arm64 --self-contained true -p:PublishSingleFile=true
cd bin/Release/net8.0/linux-arm64/publish
cp ~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1/linux/SP_lib/SP.so .
ls -lh SP_08 SP.so
./SP_08
```

| Отличие от 07 | Значение |
|---|---|
| `[DllImport("SP")]` в 07 | имя-шаблон, .NET сам найдёт библиотеку при старте |
| `NativeLibrary.Load("SP.dll")` в 08 | явная загрузка в момент работы |
| `./SP_08` только отсюда | в коде путь `"./SP.so"` — относительный, ищется от текущей папки |

**Ожидаем:** `Сложение = 15`, `Вычитание = 5`, `Умножение = 50`, `Деление = 2`

## Все четыре сразу

```bash
export DOTNET_ROOT="$HOME/.dotnet"; export PATH="$HOME/.dotnet:$PATH"
L=~/Documents/VisualStudioCodeRepos/SystemProgramming/lab1

(cd $L/linux/SP_lib && g++ -fPIC -shared SP.cpp -o SP.so) && echo "SP.so собрана"

(cd $L/linux/SP_03 && cp ../SP_lib/SP.so . && g++ main.cpp SP.so -o SP_03 && LD_LIBRARY_PATH=. ./SP_03)

(cd $L/linux/SP_04 && cp ../SP_lib/SP.so . && g++ main.cpp -ldl -o SP_04 && ./SP_04)

(cd $L/linux/cs/SP_07 && dotnet publish -c Release -r linux-arm64 --self-contained true -p:PublishSingleFile=true -v q --nologo && cd bin/Release/net8.0/linux-arm64/publish && cp $L/linux/SP_lib/SP.so . && ./SP_07)

(cd $L/linux/cs/SP_08 && dotnet publish -c Release -r linux-arm64 --self-contained true -p:PublishSingleFile=true -v q --nologo && cd bin/Release/net8.0/linux-arm64/publish && cp $L/linux/SP_lib/SP.so . && ./SP_08)
```

**Ожидаем:** четыре блока по `15`, `5`, `50`, `2`. Займёт ~2 минуты, первый `dotnet publish` дольше остальных.
