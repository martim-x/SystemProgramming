## Задание 03 — SP.so + статический вызов

```bash
cd ~/lab1/linux/SP_lib
g++ -c SP.cpp -o SP.o
g++ -shared SP.o -o SP.so
```

Показать экспорты библиотеки:

```bash
nm -D SP.so | grep -E ' T (sum|sub|mul|div)$'
```

Собрать приложение:

```bash
cd ~/lab1/linux/SP_03
cp ../SP_lib/SP.so .
g++ main.cpp SP.so -o SP_03
```

Показать, что библиотека прилинкована (в списке `NEEDED` есть `SP.so`):

```bash
readelf -d SP_03 | grep NEEDED
```

Запуск **без** `LD_LIBRARY_PATH` — упадёт (показать ошибку):

```bash
./SP_03
```

```
./SP_03: error while loading shared libraries: SP.so: cannot open shared object file
```

Запуск **с** `LD_LIBRARY_PATH` — работает:

```bash
export LD_LIBRARY_PATH=.
./SP_03
```

```
SP_03: static link (SP.so)
sum(10, 5)  = 15
sub(10, 5)  = 5
mul(10, 5)  = 50
div(10, 5)  = 2
```

Снять переменную, чтобы не мешала дальше:

```bash
unset LD_LIBRARY_PATH
```

## Задание 04 — динамический вызов (dlopen)

```bash
cd ~/lab1/linux/SP_04
cp ../SP_lib/SP.so .
g++ main.cpp -ldl -o SP_04
```

Показать, что библиотека **не** прилинкована (в `NEEDED` её нет):

```bash
readelf -d SP_04 | grep NEEDED
```

Запуск — `LD_LIBRARY_PATH` не нужен, путь указан в коде:

```bash
./SP_04
```

```
SP_04: dynamic link (dlopen)
sum(10, 5)  = 15
sub(10, 5)  = 5
mul(10, 5)  = 50
div(10, 5)  = 2
```

## Задание 07 — C#, статический вызов (DllImport)

```bash
export DOTNET_ROOT="$HOME/.dotnet"
export PATH="$HOME/.dotnet:$PATH"

cd ~/lab1/linux/cs/SP_07
dotnet publish -c Release -r linux-arm64 --self-contained true -p:PublishSingleFile=true
```

Положить библиотеку рядом с бинарником:

```bash
cp ../../SP_lib/SP.so bin/Release/net8.0/linux-arm64/publish/
```

Запуск:

```bash
cd bin/Release/net8.0/linux-arm64/publish
./SP_07
```

```
Сложение в C++/DLL/SO: 15
Вычитание в C++/DLL/SO: 5
Умножение в C++/DLL/SO: 50
Деление в C++/DLL/SO: 2
```

Показать, что всё в одном файле (self-contained, .NET внутри):

```bash
ls -lh SP_07
```
